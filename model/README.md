# DeepShield photo models

The photo API runs two pinned ONNX classifiers, plus a face detector, so you can analyze images without bringing your own dataset. One estimates AI-generation signals across the image. The other finds face crops and estimates face-manipulation signals, including some face swaps. These models do **not** detect every manipulation or prove that an image is authentic.

The pretrained model is [Community Forensics ViT-Small](https://huggingface.co/buildborderless/CommunityForensics-DeepfakeDet-ViT), distributed under the MIT license. Its underlying research trained on 2.7 million images generated by 4,803 models. DeepShield uses the FP32 ONNX file from pinned revision `ac6ee457bea904a373065754107451793b56db00`; the setup script checks the artifact size and SHA-256 before accepting it.

Face analysis uses [Deep Fake Hybrid Model](https://huggingface.co/nihal4/Deep_Fake_Hybrid_Model), an MIT-licensed ONNX classifier, together with OpenCV Zoo's [YuNet face detector](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet), also MIT-licensed. The classifier was trained and evaluated on an identity-isolated face dataset containing several face-swap methods and synthetic faces. Its output is therefore described as a **face-manipulation signal**, not proof that a specific face swap occurred. The upstream model card reports results on one test dataset; performance on other sources, edits, and image qualities may differ.

## Get the pretrained detector

From the repository root, with backend dependencies installed:

```powershell
python model/scripts/download_pretrained.py
```

The script downloads and verifies all required files into `model/artifacts/`: the 87 MB AI-generation classifier and the face classifier, its external ONNX weights, and YuNet. Model files stay out of Git; rerun the script on another computer. Override the classifier paths with `DEEPSHIELD_MODEL_PATH`, `DEEPSHIELD_FACE_MODEL_PATH`, or `DEEPSHIELD_FACE_DETECTOR_PATH`.

The AI model returns an AI-generation signal score; it does not identify which service made an image or prove that a particular ChatGPT image is AI-generated. It was trained across thousands of generator types, but performance on a specific service/version must be evaluated separately. Neither model score is a calibrated probability of authenticity. Scores may be wrong on unfamiliar generators, face-swap methods, edited or compressed photos, and images outside the training domains. The face detector uses a 0.65 confidence threshold and analyzes up to ten detected face crops; for multiple faces, the displayed score is the highest fake-class score. EXIF orientation is applied before both checks. Small, obscured, or low-quality faces can still be missed. A result with no strong signal does not mean “authentic.”

## Optional training work

The repository still contains an experimental ResNet-18 training pipeline. It is separate from the pretrained model used by the API and is not a deepfake detector until trained and evaluated on relevant data.

## Dataset

Use the split layout in [`data/README.md`](data/README.md). Train and validation classes must each be named `fake/` and `real/`. Keep identities/videos and near-duplicate frames separated between splits. Use a separate `test/` set for final evaluation and document source permissions and licenses.

## Install and train

Install a PyTorch and Torchvision build appropriate for your CPU/GPU from the [official PyTorch install selector](https://pytorch.org/get-started/locally/), then install the optional training dependencies:

```powershell
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[train]"
```

Fine-tune using your dataset:

```powershell
python scripts/train.py --data-dir data/deepfake_faces --epochs 8 --batch-size 32
```

Training uses ImageNet-pretrained ResNet-18 weights, downloaded by Torchvision on first run. It prints train/validation metrics and saves the best validation-F1 checkpoint to `artifacts/deepfake_resnet18.pt`, plus validation metrics as JSON. No dataset is included. Do not treat validation performance as final test performance.

The training script writes its checkpoint under `model/artifacts/`; the backend's default pretrained ONNX detector remains selected unless `DEEPSHIELD_MODEL_PATH` and backend code are deliberately changed. Evaluate custom weights against the held-out test split:

```powershell
python scripts/evaluate.py --data-dir data/deepfake_faces
```

The script prints test accuracy, fake-class precision/recall/F1, and a confusion matrix. Do not tune the model using this test output; that would make it no longer a held-out evaluation.

Pretrained model attributions, pinned revisions, artifact checksums, and licenses are documented in `model/THIRD_PARTY_MODEL.md`.
