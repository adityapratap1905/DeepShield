# Official FaceForensics split provenance

`train.json`, `val.json`, and `test.json` are the official source-video pair lists from `ondyari/FaceForensics`, commit `b952e41cba017eb37593c39e12bd884a934791e1`. Their SHA-256 hashes and retrieval metadata are recorded in `SOURCE.json`. The preparation pipeline validates those hashes and prevents source-video pairs from crossing partitions.
